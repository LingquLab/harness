# Session scripts

Approved scope: EXEC supports session-local named scripts and CrossZoneScript scripts pinned to commits on branches named after the bound HAPI session. No registry or manifest. Existing argv/inline execution remains compatible.

Local forms: {script, sha256, args}, {script_read}, {script_update, sha256, content} or {script_update, sha256, replacements}. Update sha256=null creates a missing script; existing files require the current SHA256. Replacements are exact, unique, sequential {old,new} pairs. Read and hash-conflict feedback returns the complete UTF-8 script and SHA256, without generic execution-output truncation. This is an explicit script-content export, never arbitrary runtime logs.

Scripts live in session state_dir/scripts, with a single filename ending .py, .sh or .ps1. Name containment is required to keep names session-local; no registration or entry manifest checks. Execution snapshots bytes after checking SHA256 and passes JSON args through --args-file. Git form: {git:"session",commit:<40 hex>,entry:<relative script path>,args:{}}. Fixed repository https://github.com/LingquLab/CrossZoneScript; branch inferred from config session_id. Fetch and pin commit, require reachability from that session branch, export ordinary files only. Never run branch HEAD implicitly. Dependencies load from the snapshot while cwd stays the run workspace.

Reuse EXEC receipt, task identity, cancellation, deadline and outbox. Script-control replies are SCRIPT_RESULT on success, REJECTED on failure, correlated to task/iteration. Feedback persists through normal outbox delivery; edits are not repeated after restart. Existing-script edits serialize with snapshotting in this process. Preparation failures are explicit and never fall back to another script version. Interrupted receipt recovery remains conservative.

Implementation: protocol and capability declaration; scripts resolver/control; executor/controller integration; local/Git regression tests; 0.8.0 metadata and role/protocol documentation. Validate local create/read/update/conflict/execute, Git branch pinning and errors, cancellation/deadlines and legacy suites. No remote script repository changes or green deployment until separately performed.
